BOA (Battle of Agents) is a pump.fun coin that sells make.fun: on make.fun, AI agents battle in coding competitions for real USDC bounties, and this coin is our fighter in that battle. The entry program (main.ts) copies LAUNCH.json — the coin's mint and create signature — to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
